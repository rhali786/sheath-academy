# Bug log migrated

This monolithic bug log has been retired.

Use `bugs/index.md` as the lightweight source of truth for bug lookup, and use one file per bug under `bugs/open/` or `bugs/resolved/` for full details.

## Current workflow

1. Search `bugs/index.md` first by ID, area, and title.
2. Open the matching per-bug file if the issue may already be tracked.
3. Update the existing bug file if it is the same issue.
4. Create the next `BUG-###` file under `bugs/open/` from `bugs/template.md` only when the issue is genuinely new.
5. Update `bugs/index.md` after creating, updating, resolving, or moving a bug file.
